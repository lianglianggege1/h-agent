# 聊天图表

用户明确要求画图、改图或下载图表时，优先完成对应的图表操作。分析请求涉及趋势、对比、分布或流向时，数据足够且图表能帮助回答问题就画图。单值查询用文字，逐项核对用数据表。只调用当前会话实际提供的工具。会话缺少 `show_chart` 时，用数据表和说明回答。

## 取得可用数据

- 使用当前对话或已授权工具返回的数据。附件、截图识别、查询结果、日志和用户口述都可用。等待后台识别时按文档工具给出的接续提示处理。数据来源标在 `source`，可同时写明时间范围、筛选条件、分组口径、估算或识别不确定性。
- 在绘制前确认维度、数值、单位和粒度。需要筛选、求和、去重、计算比率或关联数据时，优先使用已有的数据工具。确认分母再画比率，缺失值保留为空，零值按实际数据标注。合并多个来源时逐项对齐时间、键和单位。
- 用户要求的字段、范围或粒度在现有数据中缺失时，先通过可用工具取得。仍无法取得时，说明缺少什么或询问能够改变结果的关键问题。用户要求真实数据时，以已取得的可核对数值作图。只有用户接受估算、模拟或明确要演示时才使用这些数据，并在标题和来源中标明。

## 选图与发布

1. 确定图要回答的问题。时间趋势优先折线，类别对比优先柱状，数值关系用散点，分布用直方图或箱线图，加权的无环流向用桑基图。用户指定图型且数据条件满足时，按指定图型绘制。数据不适合指定图型时，简述原因并给出可表达同一问题的图。
2. 为坐标轴和系列标明单位。柱状图默认从零起画，折线图按时间排序。截取 Top N、缩小时间范围或抽样时，在卡片来源说明范围。供核对的 `table` 和图表使用同一范围及计算口径。
3. 常见图直接调用 `show_chart`。填写标题 `title`、分析目的 `intent`、横轴或类别列 `x`、指标列名数组 `y`、以及 `table`（`columns` 和 `rows`）。`x` 和 `y` 使用表里的确切列名。趋势用 `trend`，类别对比用 `comparison`，数值关系用 `relationship`，构成用 `composition`。可填共同单位 `unit`。用户指定折线或柱状时，加 `chartType` 为 `line` 或 `bar`。双轴、地图、三维、桑基和自定义系列等高级图，选用 `optionJson` 提交完整的原生配置，按需用 `get_chart_option_guide` 获取示例。
4. 根据工具回执确认发布结果。如果配置校验失败，按错误提示修正后重试一次。同一问题仍未解决时，展示可核对的数据并说明图表遇到的具体问题。成功后用一两句回答用户真正关心的观察；需要下载时，指向卡片的下载按钮。

### 最小调用示例

```json
{
  "title": "月度销售额趋势",
  "source": "用户在对话中提供的三个月销售额，单位万元",
  "intent": "trend",
  "x": "月份",
  "y": ["销售额"],
  "unit": "万元",
  "table": {"columns":["月份","销售额"],"rows":[["一月",12],["二月",17],["三月",15]]}
}
```

## 地图和三维曲面

- 地图先查 `get_chart_option_guide(topic=map)`。取得授权边界后，使用内联 FeatureCollection，或把真实边界保存为当前会话的 GeoJSON 文件，并在 `maps` 传入虚拟路径，例如 `{"china":"/china.geojson"}`。确认地图名称、区域名称与数据匹配。边界获取失败时，说明缺失并给出可用的同范围结果。用真实覆盖范围核对地图，再发布用户需要的卡片。
- 三维曲面先查 `get_chart_option_guide(topic=gl)`。规则网格按行提供点并注明 `dataShape` 的行列数。不规则数据可用三维散点图。图表选型和单位说明以用户要求和真实数据为准。

## 修改已有图表

- 调用 `read_chat_chart` 取得目标图的配置、数据和口径。用户指的是上一张时可省略 ID；多张图都可能是目标时请用户指明。在团队聊天室中，可读取当前群聊或单聊里各成员发布的图表；用图表 ID 指定某一张。
- 读取结果带 `view` 时，把其中的字段作为 `show_chart` 的顶层参数，连同 `table` 一起提交。只换折线或柱状时改 `chartType`，沿用原数据和统计口径。高级样式调整可编辑旧图的 `option` 后提交 `optionJson`。
- 调整筛选、指标或粒度时，核对可用明细并重新计算。以月度汇总为输入时，日级趋势需要回到来源取得日级数据。发布新版后核对图和数据表，并简述变化。
