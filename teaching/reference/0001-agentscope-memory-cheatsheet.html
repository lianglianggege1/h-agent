挂载点验证命令（可复跑）

M2=~/.m2/repository/io/agentscope

# HarnessAgent.Builder 有没有 longTermMemory？
javap -classpath "$M2/agentscope-harness/2.0.2/agentscope-harness-2.0.2.jar" \
  'io.agentscope.harness.agent.HarnessAgent$Builder' | grep -i memory

# ReActAgent.Builder 的挂载点
javap -classpath "$M2/agentscope-core/2.0.2/agentscope-core-2.0.2.jar" \
  'io.agentscope.core.ReActAgent$Builder' | grep -i longterm

# Mem0LongTermMemory 实现的接口
javap -classpath "$M2/agentscope-extensions-mem0/2.0.2/agentscope-extensions-mem0-2.0.2.jar" \
  io.agentscope.core.memory.mem0.Mem0LongTermMemory | head -3

结论（2.0.1 与 2.0.2 均已验证，2026-08-31）：HarnessAgent.Builder 无 longTermMemory；绕行 = HarnessAgent.Builder.fromAgent(ReActAgent)（2.0.2 仍存在）。core SPI 接口 2.0.2 无变化。
