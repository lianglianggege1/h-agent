1.把会话记录到redis中，如果用户开启了新会话就把被切换的会话存储到postgresql中
  1.1 注意用户可以多个会话sessionId,只把被切换的会话存储到postgresql里面
  1.2 当一个会话持续24小时无新请求时，也进入postgresql存储
2.修改会话session由后端生成
   2.1 在开启新会话时生成
3.前端进入聊天页规则
   3.1 如redis中无该用户的会话记录则新生成一个新会话
   3.2 如redis中有多个该用户的新会话记录，则让其选择一个，此时，其他会话保存到postgresql中，删除redis中的相关会话记录
   3.3 如redis中有一个该用户的新会话记录，则进入该会话
4.前端退出聊天页规则
  4.1 不做会话删除处理，以待用户再次返回
5.会话历史页
  5.1 会话历史页在左侧的抽屉页展示列表，点击汉堡标签后，自动展示列表，滚动分页，默认展示10条
  5.2 点击会话历史页的会话，进入会话页，且带入会话历史，也是向上滚动逐次带入，不一次加载完毕
  5.3 会话列表默认展示最后一次用户发送的信息
