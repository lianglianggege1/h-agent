# 聊天页抽屉菜单布局设计

## 背景

当前聊天页顶部右侧直接展示“我的”和“退出”入口，页面正文顶部还有一张“今日状态”黑色卡片。用户希望简化聊天页内容，并将“我的”入口改为常见的左上角菜单按钮触发的左侧抽屉形式。

## 目标

1. 移除聊天页中的“今日状态”展示卡片。
2. 将“我的”入口从聊天页顶部按钮改为左上角汉堡菜单中的抽屉入口。
3. 点击左上角菜单按钮后，从左侧滑出抽屉。
4. “我的”入口位于抽屉左下角，点击后跳转到 `/me`。
5. 保持现有聊天、系统提示词选择、流式输出、登录校验和退出登录能力不变。

## 非目标

- 不重构为全局 AppShell。
- 不改变 `/me` 页面功能和视觉结构。
- 不新增聊天历史、设置项或额外菜单功能。
- 不改变后端接口或系统提示词管理逻辑。

## 设计

### 页面结构

修改范围集中在 `frontend/app/chat/page.tsx`。

聊天页保留现有移动端窄屏容器和米色背景。正文区域删除“今日状态”卡片后，系统提示词选择卡片成为顶部主要内容，后续快捷提示词和消息列表顺序不变。

### 顶部栏

聊天页 header 调整为：

- 左侧：汉堡菜单按钮，使用两条横杠图形表示菜单入口。
- 标题区域：继续展示 `H-Agent Chat` 和 `AI 对话`。
- 顶部不再展示“我的”按钮。

### 抽屉交互

在聊天页组件内新增 `drawerOpen` 状态：

- 点击汉堡菜单按钮时设置为打开。
- 打开后显示半透明遮罩。
- 点击遮罩关闭抽屉。
- 抽屉从屏幕左侧滑入，关闭时滑出。
- 抽屉层级高于 header 和聊天内容。

### 抽屉内容

抽屉面板宽度约为 `280px`，沿用当前米白/白色、圆角、阴影的视觉风格。

抽屉内容分为两块：

- 顶部：显示 `H-Agent` 和 `菜单` 标识。
- 底部：固定在抽屉左下角，包含“我的”入口，点击跳转 `/me`。退出登录入口可同放在底部区域，用于替代原顶部“退出”按钮，保持退出能力可访问。

### 状态与数据流

- `drawerOpen` 只影响抽屉显示，不影响聊天消息、流式状态或系统提示词选择。
- 跳转 `/me` 使用 Next.js `Link`，保持现有路由行为。
- 退出登录继续调用已有 `handleLogout`，不改变认证流程。

### 错误处理

此改动不引入新的远程请求。现有聊天发送、系统提示词加载和退出登录错误处理保持不变。

### 测试与验证

- 运行前端 lint，确认 TypeScript/React 代码符合规则。
- 如项目支持，运行前端 build，确认 Next.js 页面可编译。
- 手动验证 `/chat`：
  - “今日状态”卡片不再出现。
  - 左上角显示两条横杠菜单按钮。
  - 点击菜单按钮后左侧抽屉滑出。
  - 点击遮罩可关闭抽屉。
  - “我的”位于抽屉左下角，点击跳转 `/me`。
  - 聊天发送、系统提示词切换和退出登录仍可使用。
