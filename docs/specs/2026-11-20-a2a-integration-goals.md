# h-agent A2A 接入实施目标

将 A2A 1.0 接入 h-agent 的聊天与文档链路。用户在现有入口完成远端创作、文档处理和图片交付。任务状态和产物随原会话可查，远端执行受项目身份和权限约束。 [协议研究笔记](../research/2026-11-20-a2a-learning-path.md)

## 1. 远端创作与流式恢复

**目标**　现有 A2A 故事助手能够接收 A2A 流式产物更新，并通过现有聊天流持续呈现远端创作内容。远端任务可在连接中断后重新订阅，已完成的任务可查询最终产物。

**验收**　用户在远端仍在创作时就能读到开头。生成中断网再回到会话时，可接着查看原任务的进度；若任务已完成，则看到完整结果。恢复前后的文本无重复、缺失或顺序颠倒，初稿与后续修订在聊天中可辨认。

## 2. 远端追问与同一任务续接

**目标**　远端故事 Agent 负责判断是否缺少创作信息，并通过 `input-required` 向用户发起追问。聊天呈现远端的问题，用户补充后继续原任务。

**验收**　用户只给出故事主题时，能够看到远端对风格或受众的追问。刷新页面后仍能看到任务在等待补充，回复后沿用同一 `taskId` 完成创作。用户可在会话中看到等待输入、继续处理和完成的状态。

## 3. 文档长任务与完成通知

**目标**　用户在现有入口提交 PDF 后，立即获得任务受理状态，远端继续执行解析和 OCR。任务可查询、可请求取消。页面关闭期间，远端仍能通过 A2A 推送把完成通知送达 h-agent，并归入原会话。服务重启后，任务、进度和产物仍可查询，未完成工作可恢复。

**验收**　提交需要 OCR 的扫描件后关闭页面，远端完成时 h-agent 能收到通知，用户再次打开会话即可看到结果。回调暂时不可达时，查询仍能取得最新状态与最终产物，重复通知只产生一次交付。用户请求停止后，界面显示远端确认的取消结果；若任务已先完成，则呈现实际结果。

## 4. 文件与结构化产物

**目标**　通过 A2A 交换文本、文件和结构化数据。文档 Agent 可接收 PDF 文件并返回结构化解析结果。插画 Agent 可接收故事文本并返回图片文件产物。AgentCard 按技能声明支持的输入与输出媒体类型。文件交付纳入项目的 MinIO 和聊天资源权限体系。

**验收**　上传受支持的 PDF 后，聊天和下游 Agent 可以使用页码、解析正文和质量信息。用户请求插画后，可在原会话查看图片。未获授权的用户无法访问文档和图片，调用方可以从 AgentCard 判断技能支持的文件和结果类型。

## 5. 多技能 AgentCard 与动态发现

**目标**　远端 Agent 可通过一张 AgentCard 发布多个技能。A2A 故事助手可以通过 Nacos 发现候选 Agent，按创作任务所需的技能、标签和可用能力选择远端 Agent，并通过 A2A 调用。处理状态和交付结果在原聊天会话中可查。

**验收**　用户在故事助手中请求对稿件评分时，助手能找到支持评分的在线 Agent，并在原会话展示评分结果。新增符合条件的 Agent 或原 Agent 下线后，后续请求按当前可用的候选执行。找不到合适的 Agent 时，用户能在聊天中看到明确反馈。

## 6. 多跳委派与跨服务追踪

**目标**　远端风格编辑 Agent 接收上游任务，并作为 A2A 客户端委派事实核查 Agent。编辑结果反映证据核查结论，各跳的任务关系与会话关联可追溯，调用链可在 Langfuse 中查看。

**验收**　提交带参考资料的稿件后，最终稿反映事实核查发现，并能关联到下游核查结果。Langfuse 可查看从 h-agent 到风格编辑、再到事实核查的完整调用链。下游超时、失败或证据不足时，上游呈现实际核查状态。

## 7. 认证、扩展卡片与私有技能

**目标**　公开 AgentCard 展示基础技能和认证要求。已认证的调用方可获取符合自身权限的扩展卡片，例如有权限的用户可发现并使用长篇小说模式。技能调用及远端任务操作受同一权限边界约束。

**验收**　普通用户和授权用户看到的技能与各自权限一致。普通用户直接请求私有技能时被拒绝，授权用户能在正常聊天入口完成该技能的任务。用户只可查询、订阅、续接和取消自己有权访问的任务。

## 整体验收

- 七项能力都可通过项目现有的聊天或文档入口使用，状态与产物能回到发起任务的会话。
- 远端 Agent 声明的能力与实际行为一致，独立 A2A 1.0 客户端可以验证已开放的交互。
- 正常流程与断线、重启、取消、远端失败和越权访问等场景都有明确、可观察的结果。
